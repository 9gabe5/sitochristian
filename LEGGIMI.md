# Homepage v2 — anteprima locale

Apri index.html con Safari, Chrome o altro browser. Non serve installare nulla. Ridimensiona la finestra per vedere la versione mobile, oppure usa la modalità responsive del browser.

Homepage riprogettata con foto reali, simbolo originale animato durante lo scroll, menu mobile, pulsante Chiama persistente, percorso prima seduta, FAQ, sedi e collegamento al profilo Google. Per disattivare le animazioni usa il comando nel footer; viene rispettata anche la preferenza del dispositivo.

Le altre tre pagine sono ancora la bozza v1. Tutto il copy è una proposta da approvare. Sito non pubblicato; dominio e hosting rinviati come concordato. Prima della pubblicazione completare titoli, dati professionali/privacy, corrispondenza foto/sedi e revisione del profilo Google. Logo derivato visivamente dalla tavola originale tramite CSS: sostituire con file vettoriale ufficiale quando disponibile. Favicon CG ancora provvisoria.
